PART 1  
Turnstone Agent Evaluation Writing Guidelines  
Insurance SME Review \&amp; Recommendations  
Reviewer: Karthik Goud  
Role: Insurance Subject Matter Expert (SME)  
Purpose: Review the Turnstone Agent Evaluation Writing Guidelines from an Insurance  
SME perspective and recommend improvements to make the document self-explanatory,  
training-ready, and aligned with insurance workflows.  
Executive Summary  
The current Turnstone Agent Evaluation Writing Guidelines are well organized and establish  
a strong framework for evaluating AI agents. The document clearly explains evaluation  
concepts such as Artifact Quality, Model Response Quality, Agent Trace Quality, Multi-turn  
Quality, capability ratings, and criteria-writing principles.  
However, from an Insurance SME perspective, the document is still heavily finance-oriented.  
Although the evaluation methodology is domain-agnostic, most examples, terminology, and  
scenarios are finance-specific. As a result, a new insurance reviewer can understand the  
evaluation methodology but may struggle to relate it to real insurance workflows without  
additional explanation from managers.  
The recommendations below focus on improving the document without changing its overall  
structure. The goal is to make it self-readable, self-explanatory, and easier for insurance  
SMEs to understand while maintaining the existing Turnstone evaluation framework.  
Overall Assessment  
Strengths  
The document follows a logical learning flow.  
Criteria-writing principles are well explained.  
The examples clearly demonstrate Atomicity, Verifiability, and Specificity.  
The evaluation workflow is comprehensive.  
The separation between Artifact, Model Response, Agent Trace, and Multi-turn Quality is  
clear.  
Conversation script types effectively demonstrate different interaction patterns.  
Areas for Improvement  
Although the framework is strong, the following improvements would significantly reduce the  
need for additional GVC training for insurance SMEs.  
Finding 1 – Finance-Centric Examples  
Observation  
Most examples throughout the document are based on finance use cases such as SEC  
filings, financial statements, investment analysis, CAGR calculations, and portfolio  
management.  
Although these examples correctly demonstrate the evaluation methodology, they are difficult  
for insurance SMEs to relate to without additional explanation.  
Recommendation  
Retain the existing finance examples and add one insurance equivalent example immediately  
after each major example.  
This allows reviewers to understand the same evaluation principle using familiar insurance  
scenarios without changing the overall document structure.

Finding 2 – Missing Definitions for Common Terms  
Observation  
Several terms appear throughout the document without explanation, including:  
Agent Trace  
Hedging  
Distractor  
Mixed Initiative  
Livelock  
Task Diffusion  
Correction Turn  
A new reviewer may understand the workflow but still struggle to interpret these terms  
consistently.  
Recommendation  
Expand the existing Definitions section by adding short one-line explanations for commonly  
used evaluation terminology.  
This will improve consistency across reviewers and reduce clarification questions during  
onboarding.  
Finding 3 – Overall Rating Scale  
Observation  
The document refers to an Overall Rating but does not define what each rating represents.  
Without clear guidance, reviewers may apply ratings inconsistently.  
Recommendation  
Add a simple rating reference table.  
Example:  
Rating Description  
5 Fully meets expectations  
4 Minor issues only  
3 Meets expectations with noticeable corrections

required

2 Major issues requiring significant rework  
1 Does not satisfy the requested task  
Finding 4 – Insurance Examples  
Observation  
The document explains the evaluation methodology well, but nearly all examples are finance-  
specific.  
Recommendation  
Include one insurance example alongside each major example, particularly within:  
Artifact Quality  
Response Quality  
Agent Trace Quality  
Multi-turn Quality  
This allows insurance SMEs to immediately understand how the same principles apply within  
their domain.  
Finding 5 – End-to-End Example  
Observation

The document explains each evaluation component individually but does not include one  
complete insurance workflow demonstrating the entire process.  
Recommendation  
Consider adding one complete insurance example showing:  
User Prompt  
Expected Deliverable  
Criteria  
Evaluation  
Capability Ratings  
This would help new reviewers understand how all sections connect together.  
Overall Recommendation  
The existing document provides an excellent evaluation framework. With the addition of  
insurance-specific examples, a few missing definitions, and a clearer rating reference, it  
would become significantly more effective as a self-learning guide for insurance SMEs while  
preserving the current Turnstone methodology.

Insurance Example – Artifact Quality  
Prompt  
You are a commercial property underwriter reviewing the renewal submission for ABC  
Manufacturing Ltd. Using the attached policy documents and loss runs, generate a  
professional PDF summarizing the insured details, coverage, deductibles, exclusions, loss  
history, underwriting observations, and renewal recommendation.  
Expected Criteria  
1\. The artifact is generated as a PDF.  
2\. The PDF contains the insured&\#39;s name.  
3\. The PDF contains the policy number.  
4\. The PDF contains the policy period.  
5\. The PDF contains the coverage summary.  
6\. The PDF contains the deductible details.  
7\. The PDF contains the policy exclusions.  
8\. The PDF contains the three-year loss history summary.  
9\. The PDF contains the underwriting observations.  
10\. The PDF contains the renewal recommendation.  
11\. The PDF uses consistent headings and formatting.  
12\. The PDF contains no irrelevant information.

Insurance Example – Model Response Quality  
Prompt  
You are a commercial lines underwriter reviewing the renewal submission for ABC  
Manufacturing Ltd. Using the attached policy documents and loss runs, analyze the account&\#39;s  
loss experience, identify key underwriting risks, and provide a renewal recommendation with  
supporting rationale.  
Expected Criteria

1\. The response identifies the insured&\#39;s name correctly.  
2\. The response identifies the policy period correctly.  
3\. The response extracts the total incurred losses correctly.  
4\. The response extracts the earned premium correctly.  
5\. The response calculates the loss ratio correctly.  
6\. The response analyzes the claim frequency trend.  
7\. The response analyzes the claim severity trend.  
8\. The response identifies the key underwriting risks.  
9\. The response provides a renewal recommendation.  
10\. The response provides a clear justification for the renewal recommendation.  
11\. The response contains no hedging.  
12\. The response contains no irrelevant information.

Insurance Example – Agent Trace Quality  
Prompt  
You are an insurance underwriter reviewing a commercial property renewal. Use the  
attached policy documents, loss runs, and underwriting guidelines to prepare a renewal  
recommendation and generate a one-page PDF summary.  
Expected Criteria  
1\. The agent searches the attached policy document before generating the response.  
2\. The agent searches the attached loss run before performing any analysis.  
3\. The agent references the underwriting guidelines while evaluating the account.  
4\. The agent extracts the required policy information before calculating any metrics.  
5\. The agent validates the extracted values before performing calculations.  
6\. The agent calculates the loss ratio using the extracted values.  
7\. The agent uses the calculated results to determine the renewal recommendation.  
8\. The agent validates the generated PDF before presenting the final response.  
9\. The agent completes the workflow without unnecessary or repetitive actions.

Insurance Example – Multi-turn Quality  
Prompt  
Turn 1:  
You are a commercial lines underwriter reviewing the renewal submission for ABC  
Manufacturing Ltd. Using the attached policy documents and loss runs, generate a one-page  
PDF summarizing the insured details, loss history, underwriting observations, and renewal  
recommendation.  
Turn 2:  
Please update the report by correcting the deductible from $10,000 to $25,000, remove the  
unnecessary market comparison section, and keep the rest of the report unchanged.  
Expected Criteria  
1\. The agent identifies the user&\#39;s requested corrections.  
2\. The agent updates the deductible from $10,000 to $25,000.  
3\. The agent removes the market comparison section.  
4\. The agent retains all previously correct sections of the report.  
5\. The agent regenerates the artifact as a PDF.

6\. The agent preserves the original report structure and formatting.  
7\. The response confirms that the requested changes have been applied.  
8\. The response introduces no unrelated changes or additional content.
